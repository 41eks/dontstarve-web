# 地图绘制对比

此包保留旧地图专用材质与地皮分块的独立绘制对比，不使用游戏内新的世界地皮整图，其性能数据不代表当前游戏底图。游戏内地图由 `packages/ui` 在主线程中用 DOM 绘制。两者共用 `MinimapDomView` 的世界容器和图标变换；对比页的图标是圆形占位元素，游戏使用原版图集图片。

`DomMap` 将地皮块和图标锚点放在同一个世界坐标容器内。`update(view)` 只更新容器的视口矩阵，不遍历图标，也不逐个计算屏幕坐标或写入图标样式。图标通过 `setIcons(positions)` 接收实体位置采样，复用已有节点，只更新实际变化的坐标并移除多余节点；静态图标的世界位置保持不变。

图标保持 32px 屏幕宽度和固定朝向。缩放或相机转向时，一条在图标层 ShadowRoot 中共享的 CSS 规则应用视口矩阵的逆线性部分；平移不改变这条规则。规则不通过动态 CSS 变量继承，浏览器在缩放时仍需为图标重新计算样式，不能将常数次 JS 写入等同于常数浏览器渲染成本。

性能对比须统一地图、图标数量与素材、视口、操作和清晰度，并同时观察 JS、样式计算及帧间隔。现有 Canvas 单次测试包含强制像素读回，DOM 测试连续运行拖动缩放，两者输出不能直接作为同口径性能比较。
