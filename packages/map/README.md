# 地图绘制对比

此包保留旧地图专用材质与地皮分块的独立绘制对比，不使用游戏内新的世界地皮整图，其性能数据不代表当前游戏底图。游戏内地图由 `packages/ui` 在主线程中用 DOM 绘制。两者共用 `MinimapDomView` 的百分比布局：调整容器宽高缩放地形及图标间距，图标保持固定像素大小，父容器只负责平移和旋转；对比页的图标是圆形占位元素，游戏使用原版图集图片。

`DomMap` 将地皮块和图标锚点放在同一个世界坐标容器内。`update(view)` 更新容器宽高及平移／旋转矩阵，不遍历图标，也不逐个计算屏幕坐标或写入图标样式。图标通过 `setIcons(positions)` 接收实体位置采样，复用已有节点，只更新实际变化的坐标并移除多余节点；静态图标的世界位置保持不变。

图标保持 32px 屏幕宽度和固定朝向。地皮块与图标位置使用百分比，缩放改变容器宽高，由浏览器重新布局；图标本身不缩放。相机转向时，图标层 ShadowRoot 内的一条共享 CSS 规则抵消父容器旋转；缩放和平移不改变这条规则。浏览器仍有布局和绘制成本，不能将常数次 JS 写入等同于常数浏览器渲染成本。

性能对比须统一地图、图标数量与素材、视口、操作和清晰度，并同时观察 JS、样式计算及帧间隔。现有 Canvas 单次测试包含强制像素读回，DOM 测试连续运行拖动缩放，两者输出不能直接作为同口径性能比较。
